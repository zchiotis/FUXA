# Melissa interactive layout preview v14

Open `Melissa_Preview_1920x1080_v14.html` directly in a browser. It is a standalone design preview; it requires neither FUXA nor a Node.js installation.

- Robot 1–6 and Τυλιχτικό name buttons open their respective detail screens.
- The assignment button contains one group of five pallets and one detailed photo-derived AGV with a transparent background. It opens **Αναθέσεις στα AGV**: pallets handed to AGVs and awaiting return to the wrapper. **Ιστορικό παραδόσεων AGV** is the separate screen for every pallet delivered at the wrapper. See `../AGV_FLOW_DESIGN.md` for the clarified lifecycle and deferred runtime integration.
- The five Palomats are numbered **5–4–3–2–1 from left to right**, with Palomat 1 at the far right. Each opens its own detail selection.
- Palomat 1–2 use the **EUR pallet Blue** graphic, 3–4 **EUR pallet STD**, and 5 **INDU pallet**. Three reusable SVG assets are in `palomats/`; `Palomat_Graphics_v14.svg` shows them enlarged together. The v5 tracing follows the user-confirmed photograph: broad right upper guard and lower cabinet, narrow stack opening, two large fork openings per pallet, open floor bay, left lifting column and short upper guide hardware. In v14 only the painted machine enclosure is red; the drawing geometry, hardware details and pallet artwork remain unchanged. At the user's request, v6 gives the pallets strong material colors: saturated blue for EUR Blue, warm golden wood for EUR STD and deeper wood for INDU. INDU also uses a wider pallet profile. These are schematic family distinctions, not measured equipment drawings.
- The drawn pallet stack is a fixed illustration and does not indicate a measured pallet count. The family names are design metadata, with no inferred PLC UInt values.
- Each of the 15 overview entities has a small status icon. Icons currently mean **no data** and have no signal binding.
- All 35 existing directional arrow endpoints remain distinct. SEMOLINA adds exactly one OUT arrow toward AGV. The additional circular EIDOS endpoint opens the printer menu before the wrapper curve.
- A full pallet is displayed on each of 17 conveyor OUT positions when Occupied is true. Preview controls show sample/all/none/selected occupied positions and stale indications.
- SEMOLINA (Σιμιγδάλι) is the floor position beside the upper-left door, with its own SAP/AGV screen, a single OUT toward AGV and a preview pickup button. The actual HMI command remains unavailable pending the real PLC/SAP/AGV interface; see `../SEMOLINA_DESIGN.md`.
- A selected arrow may be illuminated using the preview-only checkbox. Selection and illumination are independent from production signals.

The detail fields are layout placeholders. No PLC communication, command writes, production data or delivery events are generated by this preview. Conveyor Occupied states and the SEMOLINA request shown in this standalone file are explicitly synthetic preview states. Some proposed detail fields still require evidence and mapping before becoming operational widgets. The PLC map and all real-data validation remain separate from this design review.

The source drawing is a schematic adaptation of the user-supplied factory PDF. It uses no CAD colors. Palomat vector artwork and family assignments are defined in `server/tools/melissa/palomat-graphics.js`. Regenerate the drawing with `server/tools/melissa/generate-layout.js`, then the standalone preview with `server/tools/melissa/generate-layout-preview.js`. These generators only write static assets; they do not launch FUXA.

The user requested economy of resources until artwork/layout approval. For v8, only standalone preview files and vector images were generated; no FUXA build, runtime or CI was run.

The v9 assignment button is approximately 31% narrower. The generated AGV PNG, exact image prompt and built-in editing mode are documented in `AGV_v9_ASSET.md`. Only one image request and static preview generation were used.

The v10 top-right **Περιστροφή 180°** checkbox rotates the complete factory drawing around its centre. The header, navigation, legend and endpoint inspector stay upright. Click targets rotate with the drawing, and the choice survives navigation away and back within the preview. **Επαναφορά preview** returns the drawing to its normal orientation. This is a preview view option, with no PLC or FUXA operation.

The v11 rotation keeps all text, equipment cards, AGV/Palomat/pallet artwork and robot pictograms upright. Plant geometry and conveyor flow arrows rotate by 180 degrees; endpoint IDs and click targets remain attached to their displayed objects. Complete UI cards are counter-rotated as a unit, and their children are not rotated a second time.

The v12 preview uses a complete light theme, including all detail pages and the EIDOS dialog. Three header counters sit outside the drawing: **Σε αναμονή**, **Σε διακίνηση AGV**, **Εντός Τυλιχτικού**. The third has no explanatory subtitle. Only waiting has synthetic preview values; the other two remain unknown. See `../OVERVIEW_METRICS_DESIGN.md` for definitions and pending real-data sources.

The v13 preview adds vector Condor Robotics branding, Palomat modal dialogs with unit selection, a Barcode display name and label icon, and larger typography. `Condor_Robotics.svg` is true outlined vector artwork. See `../BRANDING_AND_DIALOGS_DESIGN.md`. No FUXA build or runtime was used.

The v14 Palomat update is paint-color only. All three variants were compared before/after: their SVG geometry is identical after color normalization, all 14 pallet groups per variant are byte-identical, and pallet-family assignments are unchanged. No FUXA build/runtime/CI or image generation was used.
