# Melissa FUXA-AGV · native / OPC UA

Προετοιμασία έκδοσης **0.4.0**, πάνω σε FUXA **1.3.4-2888**. Αντικαθιστά την υλοποίηση iframe/S7 του build 5. Το παλιό Windows πακέτο δεν αλλάζει από την τροποποίηση του κώδικα· απαιτείται νέο Windows build όταν ζητηθεί.

## Οθόνες μέσα στον editor

Το `Melissa_CPLC.fuxap` περιλαμβάνει **16 κύριες οθόνες**, περιστραμμένο overview και native αναδυόμενα: σύνολο **59 views**, **1.905 ανεξάρτητα FUXA στοιχεία**. Δεν υπάρχει iframe μέσα στα views. Τα στοιχεία είναι κανονικά Shapes, Values, Semaphores και Tables του FUXA, με ονόματα, Properties, Events και Actions. Τα γραφικά παραμένουν χωριστά αντικείμενα του editor· η κάτοψη δεν εισάγεται ως μία εικόνα ή ένα ενιαίο group.

Τα Robot 1–6, SEMOLINA, Τυλιχτικό, SAP, Αναθέσεις στα AGV, Ιστορικό παραδόσεων AGV, Barcode, Palomats, Diagnostics και Events ακολουθούν την εγκεκριμένη ονομασία και αρίθμηση. Τα Palomats και το Barcode ανοίγουν native FUXA dialogs από το overview. Τα βέλη ανοίγουν τα δικά τους native station dialogs. Η περιστροφή χρησιμοποιεί δεύτερο native view και native navigation event, με όρθια γράμματα και εικόνες.

Ο φάκελος `widgets` περιέχει τα αντίστοιχα SVG. Το `.fuxap` είναι το πλήρες project με Properties/Events/Actions· η εισαγωγή ενός μεμονωμένου SVG δεν υποκαθιστά την εισαγωγή αυτών των ρυθμίσεων.

## CPLC · OPC UA και επιλογή tags

- Συσκευή: **Melissa CPLC · OPC UA**, ID `melissa-cplc`, type `OPCUA`.
- Endpoint επιβεβαιωμένο από τον χρήστη: **opc.tcp://192.168.214.105:4840**.
- Η συσκευή αρχικά είναι disabled και η λίστα tags είναι **κενή**. Δεν έχουν κατασκευαστεί NodeIds ούτε μετατραπεί S7 offsets σε OPC UA διευθύνσεις.
- Στον υπολογιστή δοκιμών: Devices → CPLC → οι πραγματικές ρυθμίσεις ασφάλειας/πιστοποιητικών του server → ενεργοποίηση σύνδεσης → Add/Browse tags → επιλογή των επιθυμητών nodes.
- Τα νέα CPLC tags που επιλέγονται με browse έχουν αρχικά DAQ: αλλαγή τιμής + δείγμα ανά 10 s, χωρίς restore παλιάς τιμής. Η ρύθμιση παραμένει επεξεργάσιμη.
- Η σύνδεση είναι read-only όσο οι εντολές και τα interlocks δεν έχουν συμφωνηθεί. Το browse, η προσθήκη tags και η σύνδεσή τους στις ιδιότητες επιτρέπονται.

## Σύνδεση ενός tag σε στοιχείο

1. Επιλέξτε το στοιχείο στον editor και ανοίξτε τα Properties του FUXA.
2. Σε **Value**, επιλέξτε το tag που θα εμφανίζεται. Σε **Semaphore**, επιλέξτε tag και ranges/colors. Κάθε βέλος έχει δικό του **AGVRequest** στοιχείο, με προετοιμασμένα ranges 0/1 για το χρώμα του.
3. Για την εμφάνιση γεμάτης παλέτας, το χωριστό στοιχείο **Occupied** έχει δύο native Actions: Hide στο 0 και Show στο 1. Επιλέξτε το ίδιο πραγματικό tag Occupied και στις δύο Actions. Μέχρι να συνδεθεί, δεν εμφανίζεται γεμάτη παλέτα ως επιβεβαιωμένη παρουσία.
4. Σε **Table**, τα tags επιλέγονται ανά κελί από τις ρυθμίσεις του πίνακα. Κάθε SSCC, PalletType και handshake field έχει χωριστή θέση σύνδεσης.
5. Τα counters του overview έχουν δικά τους Value elements. Απαιτούν σωστούς counters/aggregates με τη συμφωνημένη σημασία, όχι τυχαία boolean stations.

Το `native-bindings.json` καταγράφει προτεινόμενη συμβολική πηγή, view, element και ακριβή property για κάθε θέση σύνδεσης. Είναι οδηγός επιλογής, **όχι ενεργό mapping ή επαληθευμένο NodeId**. Η ανάλυση DB100/DB13 του `manifest.json` παραμένει offline αναφορά.

## Kawasaki, καταγραφή και ιστορικό

Οι πέντε υπάρχουσες συνδέσεις Kawasaki για Robot 1, 2, 3, 4 και 5 παραμένουν χωριστές, με τον υπάρχοντα telnet driver STA/OPEINFO/ERRLOG και native Values/Tables. Δεν προστέθηκε αυθαίρετη σύνδεση Kawasaki στο Robot 6 Condor. Οι συνδέσεις αρχικά είναι disabled.

Οι τιμές καταγράφονται στο native FUXA DAQ. Τα παρατηρούμενα events παραμένουν στη χωριστή `data/_db/melissa-events.db`. Το native Table έχει επεξεργάσιμη επιλογή **Data source**: FUXA tags, Melissa events DB ή παραδόσεις AGV στο Τυλιχτικό. Η προβολή events διαβάζει τις τελευταίες 1.000 εγγραφές· οι παλιότερες παραμένουν στη DB. Η αποτυχία ανανέωσης επισημαίνει τις ορατές εγγραφές ως πιθανώς παλιές.

Οι αναθέσεις αφορούν παλέτες που δεν έχουν παραδοθεί ακόμη στο Τυλιχτικό. Το ιστορικό παραδόσεων διαβάζει μόνο τον `wrapper_deliveries`, διατηρώντας χωριστά τον παλιό `deliveries`. Δεν υπάρχει αυτόματος writer χωρίς επιβεβαιωμένο, συσχετισμένο event άφιξης στο Τυλιχτικό. Δεν δημιουργούνται δοκιμαστικές εγγραφές.

## Αναβάθμιση παλιού project

Σταματήστε το προηγούμενο FUXA, κρατήστε αντίγραφο ολόκληρου του `data` και μεταφέρετέ το στο νέο Windows πακέτο. Το πρώτο Start:

- αντικαθιστά μόνο τα αναγνωρισμένα παλιά iframe views με native views,
- αρχειοθετεί την παλιά S7 σύνδεση και τα tags της στο `data/_appdata/backups`, και δημιουργεί disabled OPC UA με κενά tags,
- διατηρεί ιστορικό, ρυθμίσεις, Kawasaki και custom views,
- σε επόμενες εκκινήσεις **διατηρεί τις αλλαγές του editor, τα browsed OPC UA tags, τις επιλογές και τα credentials σας**.

Το πακέτο περιλαμβάνει Node.js και τον OPC UA driver. Εκτέλεση στον άλλο υπολογιστή: `Start-Melissa.cmd`, έπειτα `http://127.0.0.1:1881/home`. Δεν εκτελείται FUXA στον υπολογιστή προετοιμασίας.

Οι στατικοί έλεγχοι και η πραγματική επαλήθευση PLC διαχωρίζονται στο [VALIDATION.md](VALIDATION.md). Δεν έγινε αλλαγή σε PLC project, DB666 ή TIA Portal. JHLI εκτός scope.
